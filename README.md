# 💡 Idea Factory

Generate novel, cross-disciplinary ideas and refine them into actionable plans using AI.

## 🌟 Features

- **Idea Generation**: Generate 10 creative, cross-disciplinary ideas from any topic combination
- **Idea Refinement**: Transform selected ideas into detailed, actionable plans with tasks, challenges, and resources
- **Visualization**: Create mind maps to visualize your ideas and their relationships
- **Mobile-Optimized**: Fully responsive design that works seamlessly on mobile devices
- **Export Options**: Download ideas and plans as text files for offline use

## 🚀 Quick Start

### Prerequisites

- Python 3.9 or higher
- Anthropic API key ([Get one here](https://console.anthropic.com/))

### Installation

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd Idea-Factory
   ```

2. **Set up environment variables**
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and add your Anthropic API key:
   ```
   ANTHROPIC_API_KEY=your_actual_api_key_here
   ```

3. **Install dependencies**

   For the frontend (Streamlit):
   ```bash
   cd frontend
   pip install -r requirements.txt
   ```

   For the backend (FastAPI - optional):
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

### Running the App

#### Option 1: Streamlit Only (Recommended for Quick Start)

The app uses Claude API directly, so you don't need to run the backend separately:

```bash
cd frontend
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`

#### Option 2: With Separate Backend

If you want to run the FastAPI backend separately:

1. **Start the backend:**
   ```bash
   cd backend
   python main.py
   ```
   Backend runs at `http://localhost:8000`

2. **Start the frontend:**
   ```bash
   cd frontend
   streamlit run app.py
   ```
   Frontend runs at `http://localhost:8501`

## 🎯 How to Use

1. **Generate Ideas**
   - Enter a topic or combine concepts (e.g., "quantum physics + storytelling")
   - Click "Generate Ideas"
   - Browse through 10 creative, actionable ideas

2. **Refine an Idea**
   - From the Results tab, click "Refine" on any idea
   - View a detailed plan with tasks, challenges, and resources
   - Download the plan for offline use

3. **Visualize**
   - Go to the Visualization tab
   - Click "Create Mind Map"
   - View your ideas as a structured mind map

4. **Export**
   - Download ideas as text files
   - Save refined plans as markdown
   - Copy Mermaid code for use in other tools

## 🌐 Deployment

### Deploying Frontend to Streamlit Sharing

1. Push your code to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repository
4. Set the main file path: `frontend/app.py`
5. Add your `ANTHROPIC_API_KEY` in the Secrets section
6. Deploy!

### Deploying Backend to Render

1. Push your code to GitHub
2. Go to [render.com](https://render.com)
3. Create a new Web Service
4. Connect your GitHub repository
5. Set:
   - **Build Command**: `cd backend && pip install -r requirements.txt`
   - **Start Command**: `cd backend && python main.py`
   - **Environment Variables**: Add `ANTHROPIC_API_KEY`
6. Deploy!

## 🔧 Extending the App

### Adding New Features

The app is designed to be easily extensible:

- **Add new endpoints**: Edit `backend/main.py`
- **Modify UI**: Edit `frontend/app.py`
- **Change prompts**: Update the prompt templates in both files

### Custom Prompts

You can customize how ideas are generated by modifying the prompts in:
- `generate_ideas()` - Controls idea generation
- `refine_idea()` - Controls plan refinement
- `create_visualization()` - Controls mind map creation

## 🛠️ Tech Stack

- **Frontend**: Streamlit (Python)
- **Backend**: FastAPI (Python)
- **AI**: Claude API (Anthropic)
- **Visualization**: Mermaid.js

## 📝 API Endpoints (Backend)

- `GET /` - Health check
- `POST /generate` - Generate ideas from a topic
- `POST /refine` - Refine an idea into a detailed plan
- `POST /visualize` - Create a mind map visualization
